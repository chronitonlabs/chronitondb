ChronitonDB news
================

Upgrade notes and user facing changes of ChronitonDB, newest first. Apache
Cassandra's own notes are in NEWS.txt.


Unreleased
----------

New features
 - nodetool version prints the node's ChronitonDB release version, for
   example "ReleaseVersion: 5.0-chronitondb3". The GitSHA line still needs
   --verbose. The new cassandra.yaml setting nodetool_release_version_enabled,
   default true, turns it off, and nodetool disablereleaseversion and
   nodetool enablereleaseversion change it until the next restart. With it
   off nodetool version prints the Apache Cassandra version as before. See
   docs/reference/release-version.md.

Rollback
 - Remove nodetool_release_version_enabled from cassandra.yaml before the node runs an Apache Cassandra binary or a ChronitonDB build older than this feature. They refuse to start on a yaml key they do not know.
