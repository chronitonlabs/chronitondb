ChronitonDB news
================

Upgrade notes and user facing changes of ChronitonDB, newest first. Apache
Cassandra's own notes are in NEWS.txt.


Unreleased
----------

New features
 - A new startup check warns when the commit log directory is on the same
   file system as a data directory. It is off by default. Switch it on with
   the entry check_commitlog_shared_disk, key enabled: true, under
   startup_checks in cassandra.yaml. The node starts whatever the check
   finds. Three counters of the type CommitLogDiskCheck count what it found.
   See docs/reference/commitlog-disk-check.md.

Rollback
 - Before a node runs an Apache Cassandra binary, or a ChronitonDB build older than this feature, remove check_commitlog_shared_disk from its cassandra.yaml, and remove startup_checks as well when it then holds no other entry.
